# GMDSOFT Design System v2.12

## Visual Identity

GMDSOFT builds industrial-grade Windows desktop applications for video production, security, and device management. The design philosophy is **precision engineering for professionals**. Every interface element maximizes operator productivity in high-stakes environments.

- Platform: Windows desktop application
- Resolution: 1920x1080 FHD (min 1280x720)
- Density: Information-dense, optimized for 8-hour operator shifts
- Modes: Light (default) / Dark (low-light monitoring)
- Seed Color: `#4681DB` — generates the entire color system

## App Shell Structure

```
+-----------------------------------------------------+
|  Windows Title Bar (H: 32px)              _ [] X     |
+----------+------------------------------------------+
|          |                                          |
|  Side    |  Content Area                            |
|  Nav     |  (padding: 24~32px)                      |
|          |                                          |
|  W: 240  |  W: Fill (min 1040px)                    |
|  (expand)|                                          |
|  W: 56   |                                          |
| (collapse)|                                         |
+----------+------------------------------------------+
```

- Title Bar: 32px, Windows-native chrome
- Side Navigation: 240px expanded / 56px collapsed (icon-only)
- Content Area: fluid width, min 1040px

## Absolute Rules

1. **Font sizes**: Only 10 / 12 / **14** / 16 / 18 / 20 / 22 / 28px. Default is 14px. No 13px, 15px, 24px.
2. **Font weights**: Only 400 (Regular) and 700 (Bold). No light, medium, semibold.
3. **Letter-spacing**: Never positive (> 0px). Only 0 or negative values allowed.
4. **Spacing**: Only 4px multiples (0, 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64, 80, 96).
5. **Colors**: Only token-defined colors. No arbitrary HEX values. Specify as `token-path #HEX` pair.
6. **States**: Every interactive element must define base / hover / pressed / disabled.
7. **Accessibility**: Never use color alone to indicate status — always pair with text. Never use icons alone — pair with labels.
8. **No emojis**: Use monoline SVG icons (16/24/32px) instead.
9. **No gradients**: Solid token colors only for backgrounds and buttons.
10. **No decorative elements**: No textures, patterns, or illustrations.

### `tokens.css` 는 정본의 subset 이다

레포 사본(`design-system/classic/tokens.css`)에 없다고 "토큰 없음" 으로 판정하면 안 된다 — 실측 기준 `DESIGN.md` HEX 83종 중 12종이 사본에 없다. 판정 순서:

1. `tokens.css` / 위 매핑표 조회
2. 미스이면 **정본을 직접 확인** — `grep -n -i '<변수명|HEX>' "$HOME/.../GMDSOFT/디자인시스템_스킬/DESIGN.md"`
3. 정본에도 없을 때만 새 값을 논의 대상으로 올린다

"가장 가까운 기존 토큰으로 대체" 는 2단계를 통과한 뒤에만 허용한다.

### Figma → 코드

1. `get_metadata` 로 구조, `get_design_context` 로 스타일, `get_screenshot` 으로 눈 대조. **링크만 받고 구현 시작 금지.**
2. `get_variable_defs` 결과를 위 매핑표로 옮긴다. 매핑표에 없으면 위 subset 절차를 탄다.
3. MCP 가 돌려주는 React/Tailwind 코드는 **참조일 뿐이다.** 산출물은 vanilla HTML/CSS 단일 파일이고, 클래스는 `.gmd-*`/`.c-*`, 값은 `var(--gmd-*)` 로 번역한다.
4. `components.md` 에 같은 컴포넌트가 있으면 **그 정의가 이긴다.** Figma 에서 뽑은 수치로 덮어쓰지 않는다.
5. 다크 토큰 6종은 WCAG AA 때문에 정본 추출값에서 의도적으로 바꾼 값이다(`tokens.css` 다크 블록 주석). Figma 에서 다시 뽑아 덮으면 대비가 깨진다 — 그 6종은 코드가 정본이다.

### 코드 → Figma

`use_figma` 계열을 부르기 전에 `/figma-use` 스킬을 먼저 읽는다. 그 위에 얹히는 규칙:

- **Always library check** — `search_design_system` + 원본 Docs 에서 실제 컴포넌트/변수 **키**를 찾아 `importComponentSetByKeyAsync` / `importVariableByKeyAsync` 로 가져온다. 한 파일 검색에서 안 나온다고 "없음" 단정 금지.
- **직접 그리지 않는다** — 라이브러리 인스턴스를 쓴다. 자작 변형·근사 박스·유사 컴포넌트 대체 금지.
- **인스턴스 fill 을 손으로 덮어쓰지 않는다** — 색은 변형(State)·토큰으로 맞춘다.
- **전부 변수 바인딩** — 색·radius·그림자·간격·테두리를 임의 HEX/값으로 하드코딩하지 않는다(`setBoundVariableForPaint` 등).
- **컨테이너 스타일은 실제 보유 노드에서 뽑는다** — 변형 루트(투명 래퍼)가 아니라 스타일을 가진 카드 노드.

### 아이콘

두 갈래이고 용도가 다르다 — `design-system/classic/icons/` 107종(`category__camelCase.svg`, 문서·스니펫용)과 `icon-library/` 2,144종(`kebab-case.svg`, 크기·스타일이 폴더: `24/outline` · `16/outline` · `16/fill` · `other`).

모든 글리프는 `fill="currentColor"` / `stroke="currentColor"` 로 정규화돼 있다. **SVG 안에 색을 박지 않는다** — 부모의 `color` 를 상속해 라이트/다크·상태색에 자동 대응한다. 루트 `<svg fill="none">` 은 보존한다. 크기는 마크업의 `width`/`height` 로 제어하고 값은 `--gmd-icon-{sm|md|lg|xl}` = 16/20/24/32 를 쓴다.
