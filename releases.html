릴리스 노트

docs 버전별로 무엇이 바뀌었는지 적는다. 2026-10-26 부터 v1.0.0 으로 다시 셌고, 그 전 번호(v2.x)의 내용은 v1.0.0 에 모두 들어 있다. 컴포넌트와 가이드마다 제목 아래에 처음 실린 버전과 마지막으로 바뀐 버전을 표시한다.

v1.0.0 2026.10.26

docs 버전을 v1.0.0 부터 다시 센다. v2.13.3 까지의 내용과 아래 변경을 합쳐 v1.0.0 으로 낸다. 이 아래의 v2.x 는 다시 세기 전 번호다.

컴포넌트 — 입력 계열 (Figma Design Kit 대조 반영)

  • Toggle .c-toggle — 바로 반영되는 설정을 켜고 끈다. 트랙 36×20(작게 28×16), 라벨과 설명. input type="checkbox" role="switch".
  • Segmented Control .c-segmented — 2~5개 중 하나를 고르는 붙은 버튼 묶음. 높이 32와 40, 고른 칸은 primary/subtle 면과 Bold.
  • Close Button .c-close — 닫기 아이콘 버튼. 24와 20, Primary, Neutral, Danger, Filled, Round.
  • Read-only Field .c-readonly — 고칠 수 없는 값. inline, block(왼쪽 줄 인용), empty. dl, dt, dd 마크업.
  • Filter Panel .c-filter-panel — 여러 값을 골라 거르는 패널. Reset 과 Confirm, 검색 유형, 결과 없음.
  • Code Input .c-code-input — 인증 번호처럼 자릿수가 정해진 값. 칸 40×48(작게 32×40), Box 와 Line, 오류와 성공.
  • Count Input .c-count — 범위 안에서 하나씩 늘리고 줄인다. 높이 32와 40, Plain, 끝 값에서 버튼 비활성.
  • Combobox 다중 선택 .c-combobox-trigger.is-multi — 고른 값을 칩으로 보여 주고 넘치면 +N.
  • Figma 값 가운데 4px 그리드, 글자 8단계, 컨트롤 높이 32/40/48 밖에 있는 값은 가장 가까운 규칙 값으로 맞췄다. 맞춘 내용은 Figma 바인딩 맵 메모에 있다.

컴포넌트 — Date&Time Picker Figma 정합

  • 카드 전체 .c-datetime-card — 날짜, 연·월, 날짜 시간, 시계, 기간 선택 카드를 Figma Design Kit v2.1 Date&Time Picker에 맞췄다. 폭 328, 헤더 좌우 24와 제목 28 Regular, 날짜 칸 40×40, 연·월 칸 높이 40 알약 모양, 월 이름 14 Regular, 이동 화살표 40, 시계 지름 256, 하단 구분선 없음.
  • 오늘 표시 링 — border-base 에서 border-control 로 바꿨다. 흰 바탕 비텍스트 대비 3:1 을 넘기기 위해서다. 비활성 날짜는 회색 면 없이 글자색만 흐리게 둔다.
  • Disabled dates 표본 — 지난달 날짜만 비활성이던 것을 Figma 처럼 오늘 이전 1~6일 비활성으로 고쳤다.
  • 하단 버튼 — CLEAR, CANCEL, OK 를 Text Link 여백 없음(.btn.btn-text.is-bare)으로 바꿨다. 날짜 선택, 날짜 시간 선택 카드도 같은 버튼을 쓴다. 전용 클래스 .c-datetime-actbtn 은 없앴다.
  • Text Link 여백 없음 .btn-text.is-bare — 높이, 패딩, 채움 없이 글자만 놓는 Text Link. hover 와 pressed 는 글자색과 밑줄로 나눈다.

컴포넌트 — 표시 계열 (Figma Design Kit 대조 반영)

  • Progress 작업 진행 표시 규칙 — GMDDS UX 정책(진행 표시)으로 확정된 진행 필드 .c-pfield, 막대 .c-pbar(빛줄기, 흐르는 막대), 단계 상태 .c-pbadge와 건너뜀, 긴 작업 카드 .c-task-card와 목록 .c-task-list, 단계와 결과 목록 .c-step-list.
  • Progress 진행 상태 배지 .c-pstatus — 작업 목록 상태 칸. 진행 중 채움, 완료, 실패, 일시 중지, 대기. 높이 24.
  • Toast 작업 완료 알림 .c-task-result — 성공, 실패, 건너뜀 건수와 결과 보기.
  • Badge 등급 .c-badge-level — 높음, 보통, 낮음, 없음. 틴트 면 + 같은 색 테두리와 글자(pressed). 24, 32, 40.
  • Card 현재 상태 .card.is-current 와 헤더 동작 .card-head-actions .c-card-iconbtn(32×32).
  • Notification Icon .c-noti-icon — 경고, 오류, 완료, 안내, 확인. Subtle 과 High, 24, 32, 40.
  • Action Bar .c-action-bar — 대상 전체를 확정하는 동작 자리. 주 동작 맨 오른쪽 하나, 보조 최대 둘.
  • 토큰 --gmd-semantic-neutral 추가(라이트 #6C757D, 다크 #868E96). 건너뜀 같은 중립 상태.

템플릿과 가이드 (Figma Design Kit 대조 반영)

  • 사이드 메뉴에 Templates 묶음 신설.
  • Account Menu .c-account — 아바타 트리거(40)와 칩형(아바타 24 + 이름), 메뉴는 Context Menu, 로그아웃은 구분선 아래 맨 끝 오류 색.
  • Window Title Bar .c-titlebar — 앱 아이콘, 제목, 제어 버튼(48×32). 높이 --gmd-titlebar-height 32, seed 면, 비활성, Popup.
  • Web App Shell .c-webshell — 헤더 64(컨트롤 40, 아바타 24), 사이드 내비 240/56, 본문 여백 24, 푸터 40 화면 바닥 고정.
  • AI 기본법 고지 — AI 라벨 .c-ai-label(영문 고정), 저장 파일 워터마크, 운용 고지 배너, 내보내기 실패 알림.
  • 다국어 대소문자 표기 — 영문 UI 문구의 컴포넌트 유형별 Title case 와 Sentence case, Do/Don't.
  • 브레이크포인트는 그리드 섹션의 6단이 Figma 와 같아 바꾼 것이 없다.
